## 📝 Notas de Implementación

### Paleta de Colores China
- **Jade Imperial:** Verde jade (#00A86B, #50C878) + Oro (#FFD700)
- **Polvo de Longevidad:** Dorado suave (#FFE4B5, #F0E68C)
- **Esencia de Rectitud:** Blanco puro (#FFFFFF) + Azul claro (#87CEEB)
- **Fragmento de Alma:** Azul-blanco pálido (#E6F3FF) + Púrpura (#9370DB)
- **Token del Vínculo de Amantes:** Rojo (#DC143C) + Oro (#FFD700)
- **Fragmento de Piedra Lunar:** Plata-blanco (#F0F0F0) + Azul suave (#B0C4DE)

### Herramientas Recomendadas
- **Aseprite** - Editor de pixel art profesional
- **Piskel** - Editor online gratuito
- **GIMP** - Con grid de 16x16 píxeles
- **Photoshop** - Con pencil tool y grid

### Especificaciones Técnicas
- **Tamaño:** 16x16 píxeles exactos
- **Formato:** PNG con transparencia (excepto bloques de ore)
- **Estilo:** Pixel art limpio, estilo Minecraft vanilla
- **Paleta:** Limitada, colores sólidos sin gradientes suaves
- **Iluminación:** Fuente de luz desde arriba-izquierda (estándar Minecraft)

## 🔄 Proceso de Reemplazo

Una vez creadas las texturas:

1. Guardar cada PNG en: `src/main/resources/assets/mythicalswords/textures/item/`
2. Para el ore block: `src/main/resources/assets/mythicalswords/textures/block/`
3. Verificar que el nombre del archivo coincida exactamente con el nombre en el prompt
4. Recompilar el mod: `./gradlew build`
5. Probar en juego para verificar que se vean correctamente
