# 📜 Complete Crafting Guide

This guide contains crafting recipes for materials and items in the Mythical Swords mod.

## ⚠️ Important Note

**Legendary Weapons are NOT craftable!**  
All mythical swords and weapons are obtained by defeating bosses. This guide covers:
- Ore processing
- Material crafting  
- Special items (Camelot Compass, etc.)

For weapon acquisition, see [BOSSES.md](BOSSES.md)

## 🔨 Ore Processing

### Mythril
**From Ore:**
```
Furnace/Blast Furnace
Mythril Ore → Mythril Ingot
```

**From Raw:**
```
Furnace/Blast Furnace
Raw Mythril → Mythril Ingot
```

### Northsteel
**From Ore:**
```
Furnace/Blast Furnace
Northsteel Ore → Northsteel Ingot
```

**From Raw:**
```
Furnace/Blast Furnace
Raw Northsteel → Northsteel Ingot
```

### Sacred Iron
**From Ore:**
```
Furnace/Blast Furnace
Sacred Iron Ore → Sacred Iron Ingot
```

**From Raw:**
```
Furnace/Blast Furnace
Raw Sacred Iron → Sacred Iron Ingot
```

## 🧭 Special Items

### Camelot Compass
**Use:** Locates nearest Arthurian Castle

**Crafting:**
```
   [Mythril] [Mythril] [Mythril]
   [Mythril] [Compass] [Mythril]
             [Sacred Iron]
```

**Recipe Pattern:**
| | | |
|---|---|---|
| Mythril | Mythril | Mythril |
| Mythril | Compass | Mythril |
| | Sacred Iron | |

**How to Use:**
1. Craft the compass
2. Right-click to search for castles
3. Follow the coordinates shown
4. Auto-updates every 5 seconds

## 💡 Material Gathering Tips

### Gathering Priority

**Early Game:**
1. Mine Mythril Ore (Y: 0-64)
2. Mine Sacred Iron Ore (Y: 0-64)
3. Mine Northsteel Ore (Y: 0-64)

**Mid Game:**
1. Farm Blazes for Sun Blessed Alloy (10% drop)
2. Hunt Phantoms for Spiritbound Leather (8% drop)
3. Kill Endermen for Dragon Fang Fragment (1% drop)

**Late Game:**
1. Defeat Ender Dragon for guaranteed Dragon Fang (100%, 2-3x)
2. Farm Wither Skeletons for Rainbow Bridge Fragment (2% drop)
3. Hunt Strays for Frozen Soul Crystal (5% drop)
