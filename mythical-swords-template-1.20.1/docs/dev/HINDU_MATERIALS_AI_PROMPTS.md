## 🖌️ Guía para Photoshop - Crear Texturas de Minecraft

### Configuración Inicial de Photoshop

1. **Crear Nuevo Documento:**
   - Archivo → Nuevo
   - Ancho: 16 píxeles
   - Alto: 16 píxeles
   - Resolución: 72 ppp
   - Modo de color: RGB
   - Contenido del fondo: Transparente

2. **Configurar Grid (Cuadrícula):**
   - Ver → Mostrar → Cuadrícula
   - Edición → Preferencias → Guías, cuadrícula y sectores
   - Cuadrícula cada: 1 píxel
   - Subdivisiones: 1
   - Color: Personalizado (gris claro)

3. **Configurar Herramienta de Lápiz:**
   - Seleccionar herramienta Lápiz (B)
   - Tamaño: 1 píxel
   - Dureza: 100%
   - Opacidad: 100%
   - Desactivar suavizado (anti-aliasing)

4. **Zoom:**
   - Hacer zoom al 800% o más (Ctrl + +)
   - Ver → Ajustar a cuadrícula (activar)

### Proceso de Creación

#### Método 1: Dibujo Manual
1. Usar la herramienta Lápiz (B) con tamaño 1px
2. Dibujar píxel por píxel siguiendo la cuadrícula
3. Usar la paleta de colores especificada
4. Guardar como PNG con transparencia

#### Método 2: Desde Imagen de IA
1. Generar imagen con IA (512x512 o mayor)
2. Abrir en Photoshop
3. Imagen → Tamaño de imagen
   - Ancho: 16 píxeles
   - Alto: 16 píxeles
   - Remuestreo: Vecino más próximo (conservar detalles definidos)
4. Ajustar colores manualmente si es necesario
5. Limpiar píxeles no deseados

#### Método 3: Usar Filtro de Pixelado
1. Crear diseño en tamaño grande (256x256)
2. Filtro → Pixelado → Mosaico
   - Tamaño de celda: 16
3. Reducir a 16x16 con "Vecino más próximo"
4. Refinar manualmente

### Consejos Importantes

1. **Sin Anti-Aliasing:** Desactivar siempre el suavizado para mantener píxeles nítidos
2. **Colores Sólidos:** Usar colores planos sin degradados (o degradados muy simples)
3. **Contraste:** Asegurar buen contraste entre colores para visibilidad
4. **Sombras:** Usar versiones más oscuras del color base (no negro puro)
5. **Luces:** Usar versiones más claras del color base (no blanco puro)
6. **Transparencia:** El fondo debe ser completamente transparente

### Guardar Correctamente

1. **Archivo → Exportar → Exportar como**
2. Formato: PNG
3. Opciones:
   - Transparencia: Activada
   - Entrelazado: Desactivado
   - Conversión a sRGB: Activada
4. Nombre del archivo:
   - `vajra_crystal.png`
   - `bamboo_reinforced_shaft.png`
   - `binding_cloth_of_the_monks.png`

### Ubicación Final

Copiar los archivos PNG a:
```
mythical-swords-template-1.20.1/src/main/resources/assets/mythicalswords/textures/item/
```

## 🎮 Sí, Photoshop sirve para Skins de Minecraft

### Para Skins de Minecraft (64x64):

1. **Crear Nuevo Documento:**
   - 64 x 64 píxeles (skin clásico)
   - O 64 x 32 píxeles (skin legacy)
   - Fondo transparente

2. **Usar Plantilla:**
   - Descargar plantilla de skin de Minecraft
   - Abrir en Photoshop como capa de referencia
   - Dibujar sobre la plantilla

3. **Mismas Reglas:**
   - Sin anti-aliasing
   - Píxeles nítidos
   - Cuadrícula de 1 píxel
   - Herramienta Lápiz

4. **Exportar:**
   - PNG con transparencia
   - Subir a minecraft.net o usar en launcher
